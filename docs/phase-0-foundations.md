# Phase 0 — Foundations

## Scope
Phase 0 establishes project bootstrap and governance artifacts so implementation can proceed with consistent standards.

## 0.1 Project Bootstrap & Governance — Acceptance Criteria
- A documented foundation plan exists and is tracked in version control.
- Compatibility policy and scope boundaries are documented.
- Coding conventions are documented for Java 15 and Maven multi-module development.
- Determinism rules for all tests are documented and mandatory for new tests.
